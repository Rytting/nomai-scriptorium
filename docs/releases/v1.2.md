# v1.2 — 整墙编辑与草稿保存

2026-09-12

书房现在可以围绕整面墙连续编辑：选择螺旋、改写、回复、查看上下文，并自动保留未完成的工作。

- 电脑端可直接点击墙上的螺旋；翻译器上下切换对话时，扫描光束同步定位，选中的消息自动居中。手机仍可通过消息框选择。
- 写作时可在多条螺旋之间连续改写，各自保留草稿；退出改写或回复会回到当前卷轴的阅读界面。
- 整墙编辑提供缩放、平移和上下选择；回复时显示所回复的内容，点击可定位父螺旋。
- 自动保存墙面、各条草稿、回复目标及视图位置；点击保存或按 Ctrl/Cmd+S，成功后显示“已保存”。
- 墙面操作支持本次会话内最多 20 步撤销／重做；输入框保留原生文字撤销。
- 添加回复保留已有螺旋的绘制；读写切换恢复原来的图形和视图。从文库阅读另一卷后，仍可回到之前保存的写作草稿。
- 页面右上侧加入裁切的宇宙之眼，延长线引向读写按钮。白天淡金、夜晚银灰；鼠标或键盘聚焦时有短暂流光，并遵循减弱动态效果设置。

已有卷轴文件和两种方言保持兼容。已写螺旋的文字编码只在明确改写时改变。
自动保存保存在当前浏览器的本地存储中，不是云端备份；撤销历史不会跨刷新保留。
改写较早或较长的螺旋时，后续螺旋仍可能为避免重叠而重新排布。
文库搜索范围仍为全库，星球图标草稿尚未替换。

验证覆盖两种方言混合卷轴、连续改写与退出、桌面／触屏选择、精确保存与恢复、
多目标草稿、撤销／重做、文库往返、形状调整后立即切换、主题与响应式布局，以及离线页面显示。
