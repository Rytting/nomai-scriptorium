# v1.1 — 挪麦文库

2026-09-07

书房现在可以通往挪麦文库：按天体、地点或说话人浏览收录的 45 个地点、143 段对话、684 条螺旋。

- 飞船日志风格界面：开机徽章、页面切换、面具选择、浅网格和条目高亮。
- 选中卷轴后，可选择在文库阅读或直接取到书房；进入书房直接定位墙面。
- 书房可随机换一批卷轴，初始预设保留，刷新时避开上一批。
- 全部收录条目都有中文。原有 219 条中文保留，缺口使用带来源键的官方回退，方便日后更新模组译文。
- 修复连续段落和分支的导入关系；白洞站按核对后的新版四段说明更新。
- 统一文库与书房的地名、人名标签，增强扫描光束的白色散光。

搜索目前仍为全库搜索。中文覆盖不代表全部既有译文已经逐句校对。
三个新星球图标已保存为 SVG 草稿，尚未替换页面中的圆球。

验证：中文优先级与占位回退、重复运行、未来模组替换、全部语料结构检查；
浏览器验证文库阅读、书房卷轴读取、随机刷新及中英文标签切换。
