# v1.2.1 — 刻录入口与卷向分布

2026-09-12

- 写作侧栏顶部的操作栏现在直接显示“刻录卷轴”，和撤销、保存放在一起；切到阅读模式时按钮归回原来的说明区。
- 新建多条螺旋默认按 60% 同向、40% 镜像分布，并把方向均匀铺开，短对话也不会因为随机值恰好全部同向。
- 从文库取下的预设卷轴使用同样的 60% 默认分布；导入 SVG 仍以卷轴本身识别出的方向为准。
- 保留已有用户手动调过的手性比例与本地草稿。

验证覆盖刻录按钮在读写模式和手机布局中的位置、导出按钮归位、2—10 条螺旋的方向分布、
多螺旋布局读回、24 组卷轴结构、72 组形状、30 组间距，以及现有自动保存和方言回归。
