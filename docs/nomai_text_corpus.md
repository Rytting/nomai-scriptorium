Documentation of all Nomai Text

Key

Nomai text is typed exactly as it is written in the game, with each new paragraph indicating the next ‘swirl’. If a Nomai conversation branches out then it is shown with a new bullet point, and carries on the same as before. If the script branches out *again*, it is shown by this bullet point. For example:

Start point

Continuation of start point

- Primary branch 1

​		Continuation of primary branch 1

- Primary branch 2

  - Secondary branch 1

  - Secondary branch 2

    Continuation of secondary branch 2



An ellipsis (...) between Nomai scripts indicates that the next script is closely related to the one before.

A dash (-) between Nomai scripts indicates that they are unrelated.

Two names of places inside curly brackets indicates the use of the ‘projection stones’ 

A ‘🎥’ symbol indicates the following Nomai text is from an audio recording.
