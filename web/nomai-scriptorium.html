We use an information-encoding glyph algorithm, so every generated result corresponds uniquely to its input and can be decoded exactly. It supports characters from many languages. Happy exploring!

Nomai spirals are nearly always signed. The unsigned ones are notices, and questions put to whoever passes.

The original dialect is on. This keeps the first author's numbering, so that scrolls from nomai-writing.com and NomaiText.jl can be read and written here. It supports neither signatures nor reply structure, and its encoding is not a strict one-to-one map, so a drawing has no single reading: translating one lists up to three that fit it. Use Unambiguous for signatures, reply structure, and a scroll that reads back exactly as written.
